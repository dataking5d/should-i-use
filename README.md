# should-i-use

只读式技术尽调 skill：当你分享一个开源仓库、包、MCP server、agent skill、框架、数据库、记忆 / RAG 系统、CLI、SDK 或技术文章，并想判断它是否值得引入时使用。

## 触发场景

- “分析这个项目 &lt;URL&gt;”
- “看看这个 MCP 值不值得我接”
- “要不要引入 X”“这个 skill 对我有用吗”
- “帮我做个技术尽调”“和我现有方案对比一下”

## 原则

- **只读**：从不安装、执行或重配任何东西。
- 从第一性原理判断一个外部技术资源是否**值得在你的系统里占一席之地**，而不是它“好不好”。
- `records/` 沉淀过往评估结论，`references/` 提供决策 playbook 与报告模板。
